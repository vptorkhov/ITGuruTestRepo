# icons/

SVG-иконки, обёрнутые в React-компоненты. Каждый файл экспортирует один компонент без пропсов.

| Компонент | Использование |
|---|---|
| `AlertError` | Иконка ошибки в Toast |
| `AlertInfoIcon` | Иконка информации в Toast |
| `AlertSuccess` | Иконка успеха в Toast |
| `Check` | Галочка внутри чекбокса |
| `ChewronLeftIcon` | Стрелка «назад» в пагинации |
| `ChewronRightIcon` | Стрелка «вперёд» в пагинации |
| `CloseAlert` | Кнопка закрытия Toast |
| `CloseCross` | Кнопка очистки поля ввода и закрытия модального окна |
| `EyeIcon` | Показать/скрыть пароль в поле Input |
| `LockIcon` | Иконка замка в поле пароля на форме входа |
| `LogoIcon` | Логотип приложения |
| `PlusCircleIcon` | Кнопка «Добавить» в меню таблицы |
| `PlusIcon` | Кнопка «+» в строке товара |
| `RefreshIcon` | Кнопка обновления таблицы |
| `SearchIcon` | Иконка поиска в поле ввода |
| `SortIcon` | Индикатор направления сортировки в заголовке таблицы |
| `SpinnerIcon` | Анимированный спиннер загрузки |
| `ThreeDotCircleIcon` | Кнопка «три точки» (заглушка) в строке товара |
| `UserIcon` | Иконка пользователя в поле логина |
