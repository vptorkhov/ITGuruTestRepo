# pages/

Страницы приложения. Каждая страница — отдельная папка с `index.tsx`, стилями и локальными компонентами.

---

## `login/`

Страница авторизации (`/login`).

- **`LoginFormWrap/`** — обёртка с логотипом, заголовком и ссылкой «Создать аккаунт».
- **`LoginForm/`** — форма с полями «Логин» и «Пароль», чекбоксом «Запомнить меня».
  - Валидация через `zod` + `react-hook-form`.
  - При ошибке API текст ошибки выводится под полем логина.
  - Если «Запомнить меня» включён — токены сохраняются в `localStorage`, иначе в `sessionStorage`.

---

## `indexPage/`

Главная страница со списком товаров (`/`). Требует авторизации.

- **`TitleBlock/`** — заголовок страницы и поле поиска с дебаунсом 500 мс.
- **`Menu/`** — кнопки «Обновить» и «Добавить».
- **`GoodsList/`** — таблица товаров.
  - `GoodsHeadRow` — заголовок с кликабельными колонками для сортировки (Наименование, Вендор, Артикул, Оценка, Цена).
  - `GoodsItemRow` — строка товара; рейтинг ≤ 3.5 подсвечивается красным.
- **`PaginationBlock/`** — счётчик «показано X–Y из N» и кнопки пагинации.
- **`AddGoodsModal/`** — модальное окно добавления товара (Название, Бренд, Артикул, Цена, Рейтинг). После успеха показывает Toast и обновляет список.

Состояние сортировки (`sortBy`, `order`) сохраняется в `localStorage`.

---

## `not-found/`

Страница 404. Выводится для любого неизвестного маршрута (`*`).
